# Deployment notes

This Vite app is ready to deploy to Vercel for a shareable demo URL.

## Live demo

Add the live URL here once the project is deployed:

```text
https://your-project-name.vercel.app
```

## Deploy to Vercel

1. Sign in to Vercel and import this GitHub repository.
2. Use the default Vite project settings.
3. Confirm the project builds using the standard `npm run build` command.
4. Deploy the project and copy the public URL into the README.

The included `vercel.json` file ensures client-side routing continues to work correctly in the static deployment.

## Notes

A live demo link cannot be created from this environment without a valid Vercel account and deployment authorization.
